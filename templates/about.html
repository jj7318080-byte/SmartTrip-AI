About SmartTrip AI

An intelligent travel planning and budget estimation system.

Project Overview

SmartTrip AI is a machine learning based travel planning application designed to help users plan trips according to their budget, destination and travel preferences.

It provides estimated travel costs, destination recommendations, itinerary planning and expense tracking through a single platform.

Project Objectives

  • Estimate travel expenses before starting a trip.
  • Recommend suitable destinations based on user preferences.
  • Help users plan trips according to their budget.
  • Organize travel schedules and daily activities.
  • Track expenses and manage saved trips.

Machine Learning Models

Random Forest Regression

Estimates the expected travel cost based on trip details and preferences.

K-Nearest Neighbors (KNN)

Recommends destinations by comparing destination features and user preferences.

Key Features

  • AI Travel Cost Prediction
  • Destination Recommendation
  • Trip Planner
  • Itinerary Builder
  • Expense Tracker
  • Saved Destinations
  • AI Travel Assistant
  • Reports and Analytics

Technologies Used

Programming Language Python
Web Framework Flask
Machine Learning Scikit-learn
Database SQLite
Frontend HTML, CSS, JavaScript

Project Benefits

SmartTrip AI helps users make informed travel decisions, understand estimated expenses and organize their journeys more efficiently. The predictions are estimates and actual travel costs may vary.
